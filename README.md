# Álbum de 10 años — versión 2

Esta versión cambia la narrativa para un cumpleaños infantil de 10 años, manteniendo una estética fotográfica, minimalista y cinematográfica.

## Estructura
01 — Hoy es tu día
02 — Diez años
03 — Con quienes quieres
04 — Así se vivió
05 — Un año más

## Fotos
La maqueta usa `01.jpg` a `17.jpg`. Son espacios de prueba; reemplázalos con fotografías reales cuando quieras.

## Publicar en GitHub Pages
1. Crea un repositorio público.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `fotos`.
3. GitHub → Settings → Pages.
4. Deploy from a branch → `main` → `/ (root)` → Save.

Para las 110 fotos, la siguiente etapa debe convertir la galería en una estructura de datos para no editar manualmente cada bloque y optimizar las imágenes para web.


## V3 — atmósfera y dinamismo
Esta versión añade:
- Fondo negro con degradados púrpura muy oscuros.
- Orbes de luz ambiental casi imperceptibles.
- Líneas luminosas que atraviesan lentamente el fondo.
- Pequeñas chispas de luz que aparecen ocasionalmente.
- Parallax muy suave en fotografías protagonistas.
- Entrada escalonada de pequeños grupos de imágenes.
- Respeto por `prefers-reduced-motion`.
La intención es que estos efectos se perciban como parte del ambiente, no como decoración evidente.
